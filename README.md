# Family Health 家庭健康管理

一个用于 DeepSeek Harness 的家庭健康管理插件：管理家庭成员档案、体检记录、疾病风险分析与就诊建议，支持关键指标趋势对比、HTML 报告导出与 PDF 体检报告导入。

## 功能亮点

- 家庭成员档案 + 体检记录管理
- 疾病风险分析（含判断依据，可折叠展开）
- 就诊科室 + 处理程度建议
- 个性化健康建议（饮食/运动/生活方式/重点监测）
- 家庭指标趋势对比
- HTML 报告导出（可分享给家人）
- PDF 体检报告导入（本地提取，中文 CID 编码支持）

## 安装

1. 在 DeepSeek Harness 中打开 **Plugins**（插件）页面。
2. 选择 **Add plugin**（添加插件）→ 从本地目录安装。
3. 选择本插件目录 `dsh-family-health`。
4. 安装后在右侧栏打开「家庭健康」。

## 数据与隐私

- 数据仅保存在当前浏览器的 localStorage，不上传服务器。
- 内置示例数据为虚构内容，仅用于演示。

## 免责声明

健康风险分析与建议仅供参考，不构成医疗诊断。请以医生意见为准，如有不适及时就医。
