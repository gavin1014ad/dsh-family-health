# Family Health 家庭健康管理

一个用于 DeepSeek Harness 的家庭健康管理插件，帮助你把全家人的体检报告、异常指标和健康风险集中管理，直观阅读、跟踪趋势，并一键生成可分享的健康报告。

## 功能

- **家庭成员档案**：为每位成员维护姓名、称谓、性别等档案。
- **体检记录**：记录每次体检的异常项（名称、详情、建议、严重程度、就诊科室、处理方式）和关键检验指标（数值、单位、偏高/偏低、参考范围）。
- **疾病风险分析**：针对每位成员，基于体检异常项给出疾病风险判断（风险名称、等级、医学依据、说明），可折叠展开查看依据。
- **就诊建议**：每个异常项标注建议就诊科室和处理程度（尽快就诊 / 近期就诊 / 定期复查 / 观察即可）。
- **健康建议**：为每位成员生成个性化建议（饮食、运动、生活方式、重点监测）。
- **指标趋势对比**：选择一项指标，横向对比家庭各成员。
- **HTML 报告导出**：一键生成带样式、可分享的 HTML 健康报告。
- **PDF 体检报告导入**：上传体检 PDF，本地提取文本并自动填入表单（支持中文 CID 编码的体检报告）。

## 使用说明

1. 安装后在右侧栏打开「家庭健康」标签页。
2. 首次打开会载入示例成员和示例数据，可直接替换为你自己的记录。
3. 点击成员头像下方的按钮可：添加体检、导出报告、编辑成员、删除成员。
4. 「添加体检」弹窗顶部可拖入 PDF，自动提取异常项和指标，再手动补充修改。

## 数据与隐私

- 所有数据仅保存在当前浏览器的本地存储（localStorage）中，不上传任何服务器。
- 示例数据为虚构内容，仅用于演示功能。
